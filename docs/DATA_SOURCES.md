# FieldShift Data Sources and Provenance

Rule: every number the product shows is either **real** (fetched by a rerunnable script from the
provider below) or labelled **illustrative**. The machine-readable version of this page is
`apps/web/public/data/catalog.json` (the UI shows it in tooltips). Nothing in the published data is
generated by a random or hash-based generator.

Farms (ids are stable): `iowa` (Story County, 42.03, -93.62), `kansas` (Finney County, 37.95, -100.85),
`baragan` (Ialomița, 44.55, 27.45; near Slobozia), `vaslui` (46.51, 27.79), `dolj` (43.91, 24.12; Oltenian
sands near Dăbuleni), `teleorman` (44.00, 25.30). Each farm is one point; weather, NDVI and soil are
sampled at that point, climate projections at its 0.25 deg cell.

## Methods

### Weather (NASA POWER)
Daily point query for 2001-2025, parameters `T2M_MAX, T2M_MIN, PRECTOTCORR, GWETROOT,
ALLSKY_SFC_SW_DWN, RH2M, WS2M`. POWER fill values (-999) are replaced by the previous valid day.
POWER is a gridded reanalysis product: it smooths local rainfall, so absolute rain totals at a field
can differ from a rain gauge.

### NDVI (MODIS)
The single 250 m MOD13Q1 pixel containing the farm point, requested together with
`250m_16_days_pixel_reliability`. Values are scaled by 0.0001; composites flagged snow/ice or cloudy
(reliability 2 or 3) or fill become `null`. One pixel can be a mixed field, so NDVI is an indicator of
season shape and drought timing, not a field-exact measurement.

### Climate scenarios (NEX-GDDP-CMIP6)
Models: ACCESS-CM2, GFDL-ESM4, MPI-ESM1-2-HR, MRI-ESM2-0, UKESM1-0-LL (first available ensemble
member, v2.0). For each model the daily `tasmax` and `pr` of the farm's 0.25 deg cell are read.
* **Growing season** = April-September. **dT** = mean daily Tmax (future window) minus
  mean daily Tmax (1995-2014), in deg C. **dP** = seasonal rainfall total (future window) divided by the
  1995-2014 total, minus 1 (fraction).
* **"2050" headline** = 2041-2060 (20-year window), for ssp245 and ssp585. The reported dT/dP are the mean
  across the five models; `p10` / `p90` are the 10th/90th percentiles across the five models (with 5 models they
  are interpolated and effectively describe the model range, not a probabilistic bound).
* **Series** (2030 ... 2090) use 10-year windows centred on each year (2050 = the headline window).
* **`monthly`**: 12 values (Jan-Dec) of dT (deg C) and dP (fraction) for the 2041-2060 window, ensemble mean.
* dT is derived from Tmax only and the app adds it to both Tmax and Tmin. NEX-GDDP-CMIP6 is bias-corrected
  and spatially downscaled (BCSD); it carries the models' own uncertainty, and projections are scenarios,
  not forecasts. Per-model values are stored under `perModel` in each `scenarios.json`.
* Because the 0.25 deg cell is ~25 km, `vaslui` and `baragan` etc. each map to their own cell; Kansas and
  Iowa likewise.

### Soil (SoilGrids 2.0)
`sand, clay, silt` in %, `soc` in g/kg, `bdod` in g/cm3, `phh2o` as pH, at 0-5, 5-15, 15-30, 30-60 and
60-100 cm. Median of the pixels in a ~2 km box around the farm. SoilGrids is a global model with
uncertainty, and the Dolj point was chosen as the sandiest cropland-like cell near Dabuleni; the
250 m grid still averages the narrow dune belts, so real local sand content can be higher.

### Terrain
Elevation and Horn 3x3 slope (percent) from SRTM 1 arc-second at ~90 m spacing. At that scale slope varies
strongly between neighbouring points in hilly Vaslui; the chosen point (4.4 %) is a plateau-slope field.

### Yields
* Romania: INS TEMPO matrix **AGR110A** (average yield, kg/ha, all holdings) divided by 1000, with county-years
  where the crop covers less than 300 ha (AGR108A) dropped. Crops: wheat (wheat and rye), barley, maize,
  sunflower, soybean, pea (field pea), sorghum where available.
* USA: values were typed in from NASS Quick Stats and are flagged `"verified": false`. Set `NASS_API_KEY`
  and rerun `python -m pipeline.yields.fetch_yields` to fetch the live values.

### Economics and quant parameters
Costs, prices and the Monte Carlo price parameters are **illustrative**: rounded reference numbers meant to
be edited by the farmer. They are not machine-fetched, and `quant_params.json` says so in its `status` and
`source` fields. `meta.calib` is empty: crop-model calibration factors need the Rust engine and are not
claimed here.

## Rerun everything
```bash
python3 -m venv pipeline/.venv && pipeline/.venv/bin/pip install -r pipeline/requirements.txt
source pipeline/.venv/bin/activate
python -m pipeline.power.fetch_weather          # NASA POWER
python -m pipeline.soil.fetch_soil              # SoilGrids
python -m pipeline.terrain.fetch_terrain        # SRTM (1 request/second public API)
python -m pipeline.ndvi.fetch_ndvi              # MODIS via ORNL (slow, cached in pipeline/cache/ndvi)
python -m pipeline.cmip6.nex_gddp --phase all   # NEX-GDDP-CMIP6 (slow, cached in pipeline/cache/cmip6)
python -m pipeline.yields.fetch_yields          # INS TEMPO (+ NASS if NASS_API_KEY is set)
python -m pipeline.validate                     # observation-only summary
python -m pipeline.quant.calibrate              # illustrative quant parameters
python -m pipeline.build_packs                  # meta from presets + merge layers + index.json
python -m pipeline.catalog                      # catalog.json
python -m pytest pipeline/tests && ruff check pipeline
```
Raw downloads go to `pipeline/cache/` (gitignored). The NCCS THREDDS server rate-limits aggressive
clients: use at most ~6 workers, and the script backs off on resets.
